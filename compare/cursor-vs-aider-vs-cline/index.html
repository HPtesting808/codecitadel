Deep Dives

⚡

Cursor — The Polished Familiar

AI-first IDE. Feels like VS Code with a PhD in your codebase.

Killer Feature: Composer

Multi-file editing with live diff preview. Say "add auth to the API" and watch it create routes, middleware, tests, and update configs across 15 files. You review, approve, done.

@codebase Chat

Ask "where do we handle webhooks?" and it searches your entire indexed codebase, showing relevant files with snippets. No more grep voyages.

Rules System (.cursorrules)

Project-specific instructions that persist. "Use Tailwind, no custom CSS. Write Vitest tests. Follow existing patterns." The familiar remembers.

✅ Strengths
  • Best-in-class UX & polish
  • Composer = multi-file magic
  • @codebase = instant context
  • Privacy Mode (Business)
  • Team features (share rules, prompts)
⚠️ Weaknesses
  • Proprietary, closed source
  • $20/mo for good models
  • Index lag on huge repos
  • No autonomous agent mode
  • Vendor lock-in risk
💰 Real Cost: $20/mo Pro = unlimited GPT-4o + Claude 3.5 Sonnet + fast requests. Business $40 adds SSO, audit logs, privacy mode enforcement.
🤝

Aider — The Terminal Purist

Git-native pair programmer. Lives in your shell. Speaks diff fluently.

Philosophy: Every Edit is a Commit

Aider doesn't "apply changes" — it creates git commits. You review with git diff, git log --oneline, git reset. Your history stays clean. Your workflow stays yours.

Repo Map (The Secret Weapon)

Instead of stuffing 100k tokens of context, Aider builds a tree-sitter powered map of your codebase: symbols, imports, call graphs. It "knows" your code without reading it all. Works on repos of any size.

Bring Your Own Keys

No subscription. You pay API costs directly. Use GPT-4o, Claude 3.5, or local models via Ollama. A 10k token session costs ~$0.05-0.15. For daily use: ~$5-15/mo vs $20 fixed.

✅ Strengths
  • Zero lock-in, open source
  • Git-native workflow
  • Any model, local or cloud
  • Pay-per-use (often cheaper)
  • Voice input (Whisper)
  • No telemetry
⚠️ Weaknesses
  • Terminal only (no GUI)
  • No multi-file "composer" view
  • You run tests/builds manually
  • Steeper learning curve
  • API costs unpredictable
💰 Real Cost: GPT-4o ~$5-15/mo for daily use. Claude 3.5 Sonnet ~$10-30/mo. Local (Ollama) = $0 after hardware. Aider cost calculator →
🧠

Cline — The Autonomous Golem

Give it a task. It plans, acts, observes, iterates. Your personal dev agent.

Autonomous Loop: Plan → Act → Observe → Repeat

You say "add Stripe checkout to the billing page." Cline:

  1. Plans: Creates todo list (research Stripe API, create webhook, update UI, test)
  2. Acts: Edits files, runs commands, installs packages
  3. Observes: Runs tests, checks build, reads error output
  4. Iterates: Fixes failures, refines, completes todos

Browser Tool = Live Research

Cline can browse the web. It reads Stripe docs, checks GitHub issues, searches Stack Overflow — all mid-task. No more context-switching to browser.

MCP (Model Context Protocol)

Connect to any external tool: GitHub API, Linear, Postgres, Redis, your internal APIs. Cline becomes a universal automation interface.

✅ Strengths
  • True autonomous agent
  • Browser research built-in
  • MCP extensibility
  • Runs commands & tests
  • Open source (mostly)
  • Any model via OpenRouter
⚠️ Weaknesses
  • Can go off-rails (needs supervision)
  • API costs can spike
  • VS Code only (for now)
  • Slower for simple edits
  • Occasional loop bugs
💰 Real Cost: Via OpenRouter: GPT-4o ~$5-20/mo, Claude 3.5 ~$10-40/mo. Local models = free. Set a budget limit in settings.
